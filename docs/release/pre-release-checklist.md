# リリース前チェックリスト

リリース(TestFlight / クローズドテスト / 本番)のたびに、**Release ビルドの実機**で確認する。
配布手順は [TestFlight](./testflight.md) と [Android クローズドテスト](./android-closed-testing.md)、
アセットや申請内容は [ストア申請チェックリスト](../store-submission-checklist.md) を参照。

## ビルド

- [ ] `app.json` の `version` が公開予定のバージョンになっている
- [ ] `npm run format:check` / `npm run lint` / `npm test` が通っている
- [ ] 開発ビルドではなく Release(production プロファイル)のビルドで確認している

## 初回起動・オンボーディング

- [ ] アプリを新規インストールした状態でオンボーディングが表示される
- [ ] 最後まで進めてホームに遷移できる
- [ ] 2 回目以降の起動ではオンボーディングが表示されない

## 日記の基本操作

- [ ] 日記の作成・編集・削除ができる
- [ ] 下書きが保持され、再度開くと復元される
- [ ] カレンダー・日別一覧で日記が正しく表示される
- [ ] ライトモード / ダークモードの両方で表示が崩れない

## アプリロック(Face ID / 生体認証)

- [ ] 設定でアプリロックを有効にできる(Face ID の権限ダイアログの文言が正しい)
- [ ] アプリをバックグラウンドから戻したときにロック画面が出る
- [ ] Face ID で解除できる(**実機のみ。シミュレーターでは確認できない**)
- [ ] 認証に失敗・キャンセルしたときに日記が見えない
- [ ] アプリロックを無効にできる

## 写真添付

- [ ] 写真ライブラリの権限ダイアログの文言が正しい
- [ ] 写真を 1 枚添付して保存できる
- [ ] 再起動後も写真が表示される
- [ ] 写真を外す・日記を削除できる
- [ ] 権限を拒否したときにアプリが落ちない

## リマインダー通知

- [ ] 通知の権限ダイアログが表示される
- [ ] 設定した時刻に通知が届く(アプリを終了した状態でも)
- [ ] 通知をタップするとアプリが開く
- [ ] リマインダーを無効にすると通知が届かなくなる
- [ ] 権限を拒否したときにアプリが落ちない

## キーボード操作

- [ ] 入力中にキーボードが入力欄や保存ボタンを隠さない
- [ ] キーボードを閉じる操作ができる
- [ ] 画面の小さい端末でも入力・保存ができる

## エクスポート / インポート

- [ ] バックアップを書き出して共有できる
- [ ] 書き出したファイルを読み込んで日記が復元される
- [ ] 不正なファイルを選んだときにエラー表示され、既存データが壊れない

## Release ビルド固有

- [ ] 全画面でボタン・リスト・タブがタップできる(開発ビルドでは再現しないタップ不能がないか)
- [ ] 起動直後にクラッシュしない
- [ ] アプリを強制終了して再起動してもデータが保持される
- [ ] アップデートインストールで既存データが保持される

## 設定・その他

- [ ] プライバシーポリシー・利用規約のリンクが開ける
- [ ] アプリ名・アイコン・スプラッシュが正しく表示される
